# MT5 AutoTrader V8 Roadmap

- MetaQuotes-Demo only; hard safety lock.
- Real MT5 Balance/Equity; no virtual $10K.
- EURUSD, GBPUSD, USDJPY, USDCHF, XAUUSD, USDCAD.
- M15 closed-candle strategy signals.
- Break-even after configurable R.
- ATR trailing stop.
- Optional partial take-profit (disabled by default).
- Maximum time in trade.
- Daily starting-equity loss guard.
- Position and total-risk limits.
- Broker stop/freeze and spread checks.
- Restart recovery.
- STOP_V8 / PAUSE_V8 / RESUME_V8 controls.
- Fixed-width DEXORZO dashboard and CSV journal.

The separate 60-second smoke test validates Demo order placement independently of strategy signals.
