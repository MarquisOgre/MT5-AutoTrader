# MT5 AutoTrader V8 — DEMO ONLY

V8 adds trade management/protection to the MetaQuotes-Demo execution stack.

Run **run_v8_demo.bat** for the normal bot.

Run **run_v8_smoke_60s.bat** for a controlled one-minute execution check. It opens one 0.01-lot EURUSD Demo position for 60 seconds and then closes it automatically. It tests order execution, not strategy profitability.

The live/real-money server is hard-rejected.
