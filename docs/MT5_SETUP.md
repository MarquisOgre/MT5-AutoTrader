# MetaTrader 5 Setup

## Prerequisites

- Windows
- MetaTrader 5 desktop terminal
- Python 3.14 or compatible Python supported by the installed packages
- A MetaQuotes demo account for V7.x testing

## Checklist

1. Install MetaTrader 5 and sign in to the demo account.
2. Keep the terminal running.
3. Make sure the required symbols are visible in Market Watch.
4. Install Python requirements.
5. Run the V7.1 demo launcher.
6. Verify the dashboard reports MetaQuotes-Demo before allowing execution.

Never put your MT5 password or other credentials into source files or Git.
