# MT5 AutoTrader V6 — Paper + Demo

V6 turns the research stack into a real-time signal/execution architecture.

**PAPER:** reads live MT5 data, uses closed candles, generates consensus signals and sends zero orders.

**DEMO:** can send orders to the connected MT5 demo account and adds spread checks, daily-loss and position limits, SL/TP and risk-based volume sizing.

V6 has no real-money/live-account mode. Historical and paper results do not guarantee future returns.
